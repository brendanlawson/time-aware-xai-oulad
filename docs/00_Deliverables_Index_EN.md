## How to reproduce everything

```bash
python setup_raw_data.py                 # verify raw CSVs + manifest
python -m src.data.time_utils            # checkpoint_map.csv
python -m src.data.build_master_table    # master_raw.parquet (+ logs)
python -m src.data.make_checkpoints      # six checkpoint datasets
python -m src.eda.eda                    # figures + eda_findings.json
pytest tests/test_leakage.py             # 16 leakage/split tests
```

See `docs/10_Reproducibility_EN.md` for details.
